# Этап 2 — арт «Обсидиан и огонь»: утверждённое

Утверждено пользователем 2026-11-07 по листам `samples/mockup.png` и `samples/fonts.png`.

## Шрифты (кириллица обязательна)

- Заголовки и таблички (`--display`): **Philosopher 700** (и 400 для мелких заголовков при необходимости).
- Кнопки, цифры, подсказки (`--ui`): **PT Serif 700** (и 400 для обычного текста).
- Cinzel и Marcellus не поддерживают кириллицу — отказались.

## Стиль (утверждённые образцы)

- `samples/panel.png` — табличка: полированный чёрный обсидиан, гравированная золотая рамка-меандр (greca), квадратные нефритовые вставки в серединах сторон, золотые заклёпки в углах. Ровный фронтальный свет, без свечения.
- `samples/sunstone.png` — Солнечный Камень: тёмный тёплый камень, золотая инкрустация, суровое лицо в центре, гладкое кольцо без делений, узкий обод с меандром и четырьмя нефритовыми ромбами. Прозрачный фон (альфа внутри 253 — при экспорте довести до 255).
- Кнопки — обсидиановые плиты с **тонкой** золотой кромкой (не с меандром, как табличка). Свечение — только у нажатой/активной.
- Сектора круга рисуются кодом по кольцу между радиусами ≈ 54 и 83 в viewBox 0 0 200 200 (замерено на `sunstone.png`).

## Промпты образцов

Брифы, по которым получены образцы: `samples/brief-panel.txt`, `samples/brief-sunstone.txt` (референс настроения — `docs/superpowers/specs/assets/b-obsidian.png`, только материал). Серия задачи 4 пишется в том же языке и с теми же ограничениями: без текста, без свечения, вид строго спереди.
