# Браузерные проверки (Playwright)

`run.js` проходит 16 сценариев в Firefox (главный браузер игрока), WebKit (вместо Safari) и Chromium. Среди них: первый запуск и пролог, уровни на всех сложностях, лианы, проигрыш по времени, перенос старого сохранения, перенос прогресса кодом, порядок сцен в конце главы и раскладка на четырёх окнах: 1366×768, 1366×650, 390×844 и 360×740 (кнопки не меньше 56px, страница не уходит вбок). Звук выключен: флажок игры `sun-treasures-muted` плюс заглушение в самом браузере.

Игровой экран «Обсидиан и огонь» проверяется так:

- «Спокойно»: на табличке времени знак `∞`, у `body` нет `data-urgency`.
- На десктопе круг Солнечного Камня состоит ровно из 20 секторов. После победы на уровне 1-01 первый сектор заполнен (каменный осколок), не `empty`.
- Большой счёт `1 234 567` (через `__SUN.setScore`) виден целиком: текст полный, `scrollWidth <= clientWidth`, табличка не вылезает за окно. Проверяется на всех четырёх окнах.
- При 1366×650 игровой экран не прокручивается по вертикали.
- В проверке `file://` шрифт Philosopher (кириллица) загружается с диска.

Скриншоты игрового экрана лежат в `$E2E_OUT/shots/<браузер>/`: `desktop-L4-level.png` (1366×768) и `mobile-L4-level.png` (390×844).

Playwright ставится **вне проекта**, у игры зависимостей нет:

```bash
mkdir -p /tmp/pw && cd /tmp/pw && npm init -y && npm i playwright && npx playwright install firefox webkit chromium
# из корня игры:
python3 -m http.server 8775 &
NODE_PATH=/tmp/pw/node_modules node tools/e2e/run.js
```

Правила запуска:

- Запускать один процесс `run.js` за раз. Браузеры по аргументу (`firefox`, `webkit`, `chromium`) параллельно не запускать. Без аргумента `node run.js` сам проходит их по очереди.
- `python3 -m http.server` может обрывать соединения под нагрузкой (`ERR_CONNECTION_RESET`). Если это случилось, перезапустить прогон этого браузера. Сервер к `run.js` не привязан, его запускают отдельно, как выше.
- Код выхода `run.js` равен 0, если все сценарии прошли, и 1, если упал хотя бы один.

Скриншоты и `results-*.json` пишутся в `$E2E_OUT` (по умолчанию `<tmp>/hranitel-e2e`). Корень игры задаёт `GAME_ROOT`, порт задаёт `PORT`.
